# ADR 0013:memory-helper 与 http-helper 的代码预算例外

- 状态:已接受(临时例外;代码先落地,本 ADR 追认)
- 日期:2026-11-24
- 复议日期:2027-06-30
- 相关:[tool-memory-helper.md](../tool-memory-helper.md)、[tool-http-helper.md](../tool-http-helper.md)、AGENTS §5.3/§12、[ADR 0010](0010-session-jsonl-budget.md)

## 1. 背景

AGENTS §5.3 规定「单个插件 ≤ 800 行」。两个 TS 工具插件实测越线:

| 插件 | 生产代码 | 内容 |
|---|---|---|
| `plugins/tool/memory-helper` | 987 行(单文件 `plugin.ts`) | 记录模型、中文分词(Intl.Segmenter + bigram)、BM25 排序、去重/合并、淘汰、自动召回、7 个工具 |
| `plugins/tool/http-helper` | 802 行(单文件 `plugin.ts`) | HTTP 请求(重定向/压缩/截断)、三种搜索后端、HTML 提取、64 KiB 可见正文 |

两者都是**一个插件只做一件事**(记忆 / HTTP),越线的原因是「一件事」本身在 TS 里没有可复用的基础设施:

- 没有 `@ada/sdk` 类型与共享工具,`ToolSpec`/`ToolResult`/`Ctx`/`clampInt`/`utf8Len` 等样板每个插件各写一遍;
- 没有可共享的 JS 模块(`compile` 只允许相对导入与宿主注入模块),检索/HTML 工具函数无法下沉;
- 拆成多个 TS 文件只能改善阅读,不改变插件总行数(预算按插件计)。

`scripts/guard.ps1` 的单插件预算检查只统计 `plugins/{provider,policy,core,tool}` 下的 `*.go`,
所以这两个 TS 插件当前不会被 CI 拦下——例外必须显式记录,否则就是「规则写了但没人守」。

## 2. 决策

在 **2027-06-30 前**,允许两个插件的生产代码上限:

| 插件 | 上限 | 附加约束 |
|---|---|---|
| `memory-helper` | 1100 行 | 仍是「长期记忆」一个职责;不得把技能/任务/会话管理塞进来 |
| `http-helper` | 900 行 | 仍是「HTTP 请求 + 搜索」一个职责;不得把爬虫编排、站点专用解析塞进来 |

附加要求:

1. 新增能力先问「是不是该进 `platform/`(如 `platform/redact` 那样)或 `@ada/sdk`」,再考虑加行;
2. 该插件超过上限时必须重新评审,优先补 SDK/共享模块,而不是继续放宽;
3. 测试不计入预算,但契约测试(生成→装配→调用、静默失败可见)必须保持全绿。

## 3. 替代方案(至少两个)

| 方案 | 做法 | 否决理由 |
|---|---|---|
| A. 立即补齐 `@ada/sdk` | 把 ToolSpec/Ctx/工具函数抽成类型包 + 注入模块,再压到 800 行 | 正确的长期方向,但 SDK 是执行层改动(新注入模块 + 版本),不该塞进一次「修重复」里;ADR 到期前完成 |
| B. 拆成两个插件 | `memory-store`(存储)+ `memory-recall`(检索) | 两者共享同一份记录模型与文件格式,拆开后要么互相 import(违规),要么通过服务传递大对象(违反 P8);检索没有独立产品价值 |
| C. 缩小功能 | memory 去掉自动召回、http 去掉三种搜索引擎 | 这两块正是插件存在的理由(按需召回、可替换搜索后端),删掉等于用「预算」掩盖「不实现」(违反 AGENTS §0 红线 6) |
| D. 本 ADR | 临时放宽到 1100 / 900,并把方向钉在 SDK | 保留一个可替换实现,代价是两处体量例外,且有明确到期日 |

## 4. 影响面

- 不改变运行时行为与任何 seam 契约;
- `scripts/guard.ps1` 不统计 TS 插件,本 ADR 只在评审时作为判据;
- AGENTS §5.3 的例外清单增加这两项,并附复议日期;
- 后续补 `@ada/sdk` 时,两个插件应同步瘦身并回滚本 ADR。

## 5. 回滚方式

补齐 SDK/共享模块、两插件压回 800 行以内后删除本 ADR;无数据迁移、无配置变化。

## 6. 复议条件

- 任一插件超过上表上限;
- 或 `@ada/sdk` / JS 共享模块落地(此时应立即重新评估是否还需要例外);
- 或记忆/HTTP 能力拆分到新的 seam/provider。
