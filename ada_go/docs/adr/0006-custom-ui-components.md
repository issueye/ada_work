# ADR 0006:受控的自定义 UI 功能包（反转「插件不画 UI」）

- 状态:提案(待评审;通过后同步主设计 §2.2/§9.4/§14.3 与 AGENTS §0)
- 日期:2026-11-20
- 复议日期:2027-06-30
- 相关:[ui-framework.md](../ui-framework.md) §7/§9、[plugin-kernel-design.md](../plugin-kernel-design.md) §2.2/§9.4/§14.3、[ADR 0005](0005-ui-infrastructure.md)、AGENTS §12

## 1. 背景

主设计 §2.2 把「插件自绘 UI」列为 v2 非目标，§14.3 的口径是「插件产数据、宿主渲染」。这套口径在 mygo 原生宿主里成立，但本设计的目标包含「组件/组件包实现一项功能」与「远程加载、不重新打包」:只靠 `Page/Section/Item` 无法表达复杂交互(文件树、编辑器、画布、时间线)。

因此需要一次**有意的反转**:允许受信插件提供自定义功能包，但把它限制在内容区与信任等级内。否则要么放弃单组件/组件包需求，要么偷偷把反转塞进实现——后者违反 AGENTS §12。

## 2. 决策

1. 默认路线仍是 `render: "host"` 的声明式页面;**自定义 `.aui` 是例外**。
2. 只有 `builtin`/`official`/`verified` 可以进主 realm 执行自定义功能包;`third-party`(含签名但未审核)不允许，只能声明式页面或 iframe 隔离岛(U2)。
3. 自定义功能包只替换**内容区**;导航、页头、空态、错误态、确认框、全局弹层由宿主/标准组件负责，插件不能替换 chrome。
4. 同域运行即完全可信:自定义功能包与宿主同权，caps 只做归因/防误用，不是沙箱(见设计 §9.2)。安装确认必须用「与宿主同权」的措辞，而不是「受限权限」。
5. 自定义功能包仍需遵守:作用域 CSS、设计令牌、i18n、a11y、无 `eval`/`innerHTML`/全局选择器、只画内容区。
6. 未签名本地开发由 `ada ui dev --allow-local-ui` 临时放行(loopback)，生产宿主不提供。
7. 功能粒度:一项功能 = 一个组件(单组件包)或一个组件包(多组件);包内组件私有，不跨包引用;一个插件最多一个功能包。

## 3. 替代方案(至少两个)

| 方案 | 做法 | 否决理由 |
|---|---|---|
| A. 只保留声明式页面 | 删除 `.aui` 与自定义功能包，全部 Page/Section/Item | 满足不了「单组件/组件包」与复杂交互;插件价值退化为数据表单;与用户需求冲突 |
| B. 自定义功能包只跑 iframe | 所有 `.aui` 进独立 origin 的隔离岛，RPC 渲染 | 弹层/焦点/尺寸/主题继承代价高;常规产品体验不可接受;U2 仍可作第三方降级路径 |
| C. 插件完全自绘(含 chrome) | 插件接管导航/窗口 | 破坏宿主统一与可替换性;直接违反 AGENTS #12;不可回滚 |
| D. 自定义功能包 + 本 ADR | 仅受信插件、仅内容区、默认声明式 | 满足需求;把反转显式化、可审计、可回滚 |

## 4. 影响面

- 主设计:§2.2 非目标需改为「默认宿主渲染，受信插件可提供受控自定义功能包」;§9.4 贡献表增加 `component`;§14.3 mygo 规则需说明 web/desktop 共用同一套内容区组件。
- 信任:自定义 UI 插件按 `verified` 及以上安装;安装 UI 必须显示「与宿主同权」;第三方只能声明式/隔离。
- 安全:同域信任边界不变;caps 不因本 ADR 变成沙箱;审批不能用同域对话框替代。
- 代码:新增 `ui/` 编译/运行时、`host/web`、`plugins/ui/*`;`kernel/` 不改。
- 测试:新增编译 golden、渲染一致性、信任矩阵、拒绝矩阵;第三方自定义 UI 必须被拒。
- 文档:AGENTS #12 的措辞需要从「插件不画 UI」改为「插件默认产数据;受信插件可提供内容区组件(ADR 0006)」。

## 5. 回滚方式

删除自定义功能包路径与 `kind=ui`/`ui` 清单段，保留声明式页面与 `ada:surface` 的宿主渲染;已装自定义功能包回退为「只显示声明式页面」或禁用。无数据迁移;`kernel/` 与既有 Go 插件不受影响。

## 6. 复议条件

- U1 的声明式页面覆盖了真实插件需求，且自定义功能包只带来边际价值 → 回滚到方案 A。
- 第三方生态要求自定义 UI，但同域信任不可接受 → 转向方案 B(iframe)并重做 U2。
- mygo/desktop 无法复用同一套内容区组件 → 重新评估本 ADR 与 ADR 0001。
